# 黑狗音乐 · Black Dog Music

一个帮助你**从零打造私人音乐库和个人音乐软件**的项目：在电脑上收集、整理音乐，配好封面和歌词，再放进手机，用黑狗音乐收听、收藏和管理。

项目包括 Android 音乐 App、音乐整理与入库指南、可选电脑工具，以及可交给 Agent（任务型 AI 助手）执行的提示词。App 不内置在线曲库或下载器，没有广告、会员和社区；获取文件与 AI 整理在 App 外完成。

**公开测试版：v0.4.7-beta.2** · App 0.4.7 / build 2013 · Android 7.0+ · ARM64 · 自有代码 MIT

[下载安卓 APK](https://github.com/chenjiateng384-cyber/blackdog-music/releases/tag/v0.4.7-beta.2) · [从零搭建音乐库](docs/LOCAL_MUSIC_COLLECTION_GUIDE.md) · [使用方法](#使用方法) · [从源码运行](#从源码运行) · [反馈问题](#反馈与参与)

## 项目解决什么问题

面向想拥有自己的音乐收藏和专用音乐 App 的用户，黑狗音乐把获取、整理、手机收听和长期保存连成一条路线：

- **文件整理好了，却不好浏览和播放**：直接按原来的目录、歌曲、歌手和专辑浏览，不必重新搬运文件。
- **只想听自己的收藏，不需要在线平台内容**：围绕本地音乐提供搜索、歌单、封面、歌词和连续播放。
- **收藏和歌单容易随卸载丢失**：提供外部备份与恢复入口。音乐文件仍需单独备份，App 不提供云同步。

完整流程：**选音乐与版本 → 获取文件 → 配封面与歌词 → 整理电脑音乐库 → 复制到手机 → 扫描、听歌和建歌单 → 备份维护**。没有现成曲库也可以从几首歌开始，不需要先学会编程。

## 主要功能

- **按自己的方式整理**：按歌曲、歌手、专辑和真实文件夹浏览；支持本地搜索，不打乱原目录。
- **管理收藏与歌单**：喜欢歌曲、创建和编辑歌单、添加歌曲、自选歌单封面。
- **连续听歌**：底部小播放器、完整播放页、播放队列、后台播放和系统媒体控制。
- **使用本地封面与歌词**：读取内嵌封面、本地图片和 LRC，支持歌手文件夹中的专用封面。
- **两种本地选歌方式**：随心听直接连续播放；智能播放先浏览候选，再自己选择。首页支持下拉刷新。
- **决定哪些歌不被推荐**：加入“仅手动播放”后，歌曲仍能搜索、收藏和手动播放，但不进入随心听与智能播放。
- **留下自己的音乐记录**：保存播放历史、听歌统计与音乐档案；导出和恢复收藏、歌单及相关设置。

可扫描格式：FLAC、MP3、WAV、M4A、AAC、OGG、OPUS。具体文件能否解码仍取决于编码与设备，平台加密缓存不能直接当作普通音乐文件使用。

## 音乐、封面和歌词从哪里准备

按项目作者在 WorkBuddy 中保存的使用经验，可先从下面两个常用入口查找歌曲、版本和合集。它们是第三方网站，不是 App 自带曲库；当前可用性与资源条件见表。

| 入口 | 原有使用经验 | 本次核对情况（2026-11-04） |
| --- | --- | --- |
| [无损音乐下载](https://flac.music.hi.cn/) | 查找歌曲、不同格式/音质和版本，并配套查找歌词、封面 | 首页免责声明可读；未实际下载验收，不能保证每条资源和附件可用 |
| [熊猫无损音乐](https://www.xmwsyy.com/) | 按歌手、分类找资源，经页面提供的网盘入口获取；作者也用来寻找合集/歌单整包 | 本次访问超时；历史能力与整包内容尚未重新验证 |

下载前先核对**歌名、歌手、录音版本、格式、附件和使用条件**。第一站的公开声明限定资源用途，不能视为长期收藏或再分发许可；有明确授权下载的艺术家页面或数字商店也是获取途径。找不到、需要登录或访问失败时先说明，不保证能取得所有音乐。

- **音乐与整包**：正常浏览资源页，下载到电脑暂存目录；整包先解压检查，不直接覆盖曲库。文件集合不会自动变成 App 内的歌单。
- **专辑/歌手封面**：可从购买附件、官方作品页面或 Cover Art Archive 查找，由能联网和保存文件的 Agent 协助；下载真实图片，不用生成图冒充原封面。
- **歌词**：先检查下载附件是否含匹配版本的 `.lrc`，缺失时再查歌词来源；普通文本不等于同步歌词。

具体操作：[音乐获取、封面歌词与手机传输完整教程](docs/LOCAL_MUSIC_COLLECTION_GUIDE.md) · [可复制给 WorkBuddy、豆包等 Agent 的任务提示词](docs/MUSIC_OPERATIONS.md#h-让-agent-查找并下载封面)。工具能否直接下载取决于其联网、文件访问和账户授权；纯聊天工具只能提供候选与步骤。

## 安装方法

**普通用户下载 APK 即可，不需要编译代码。** 进入 [v0.4.7-beta.2 发布页](https://github.com/chenjiateng384-cyber/blackdog-music/releases/tag/v0.4.7-beta.2)，在 Assets（附件）中下载 `blackdog-music-v0.4.7-beta.2-android-arm64.apk`。若发布页暂不可访问，则仍处于发布准备阶段，以实际附件为准，不从陌生网站寻找所谓“官方版”。

- 当前安装包面向 **Android 7.0+、64 位 ARM 手机**，主要验收设备为一加13。
- 暂不提供 iPhone、iPad 或电脑播放器。电脑端整理工具不是桌面版音乐 App。
- 安装附件只有 `.apk` 是手机安装包；`Source code.zip` 是源码，`SHA256SUMS.txt` 用于核对文件是否损坏，许可证文件不是安装包。
- 本版使用维护者的专属签名，未上架应用商店；它是公开测试版，不是已经完成全机型验收的稳定版。发布范围见[发布说明](docs/PUBLICATION_STATUS.md)。

测试版仍有未完成的验收场景，不承诺全机型无 Bug。发布进度与已知限制见[发布检查](docs/RELEASE_READINESS.md)和[实际验收记录](docs/FIRST_USER_WALKTHROUGH.md)。

下载后：

1. 把 `.apk` 保存到手机，在文件管理器中打开。
2. 按系统提示完成安装；如果需要安装授权，只为打开该 APK 的应用授权，不必全局关闭安全防护。
3. 打开“黑狗音乐”，按下一节选择音乐目录。

**更新旧版本前先导出备份。** 早期私人测试包使用调试签名，不能直接被本版覆盖；自行编译的包也可能签名不同。若提示签名不一致、版本过低或无法安装，停止并反馈，不卸载、清数据或强制降级。开发者可按[从源码运行](#从源码运行)自行编译。

**尚未完整验收的场景**：新生产签名 APK 的独立 Android 新装/备份恢复、卸载后目录重新授权、两小时连续播放及完整耳机/音频焦点矩阵。本版不把这些未完成项标成通过；重要收藏请始终另存外部备份，建议先用少量音乐试用。

## 使用方法

安装后：

1. **准备音乐**：把自己有权使用的音频放到手机固定目录，例如 `Music/我的收藏`。
2. **选择目录**：打开“我的 → 主音乐目录”，通过系统文件选择器授权该文件夹。
3. **扫描并播放**：扫描完成后，从音乐库点歌；点击底部小播放器进入完整播放页。
4. **保存收藏**：添加喜欢或创建歌单后，在“我的 → 数据与备份”导出一份外部备份。

新增歌曲时，复制到原目录，再执行“我的 → 重新扫描音乐”，不需要卸载重装。需要本地歌词时，把同名 `.lrc` 放在音频旁，例如 `歌曲.mp3` 与 `歌曲.lrc`。

详细步骤与常见问题见[第一次使用](docs/QUICK_START.md)。

日常操作：播放页的“加入歌单”可把当前歌曲放入已有或新建歌单；随心听适合直接连续听，智能播放适合先浏览再点选。不希望自动推荐的歌可设为“仅手动播放”，仍然可以手动收听。

## 输入与输出示例

以下文件名、歌单名和歌词均为示意，不是项目附送的音乐资源。

### 示例一：本地文件变成可浏览的音乐库

**输入**：手机中有一首可正常解码的 MP3，标题标签为“晨光”、歌手标签为“示例歌手”，目录如下：

```text
Music/我的收藏/
└─ 示例歌手/
   ├─ 晨光.mp3
   ├─ 晨光.lrc
   └─ cover.jpg
```

`晨光.lrc` 内容示例：

```text
[00:10.000]晨光落在窗台
[00:15.500]今天慢慢走来
```

**操作**：选择 `Music/我的收藏` 为主音乐目录，扫描后搜索“晨光”并点歌。

**输出**：歌曲列表和搜索结果中可找到“晨光”；文件夹页保留原目录层级。没有内嵌封面且图片有效时，目录中的 `cover.jpg` 可用作封面；同名 LRC 提供整句歌词时间。原音频不会被复制或改写，歌词是否准确取决于时间戳是否匹配该音频版本。

### 示例二：收藏与歌单变成外部备份

**输入**：把“晨光”标为喜欢，加入“散步”歌单，然后执行“我的 → 数据与备份 → 导出备份”。

**输出**：在系统窗口选择的位置生成一个 `.harmonybackup` 文件，包含收藏、歌单、播放历史及受支持的长期设置和人工资源，**不包含原始音乐**。以后可通过“从备份恢复”导入；恢复会整库替换，不会把两份数据合并。

## 数据与歌词：先了解这几点

- **音乐默认只读**：App 不替你移动或改写原始音乐文件。喜欢、歌单和历史另外保存在本机数据库中。
- **卸载前先备份**：导出 `.harmonybackup` 到 App 目录外，再复制一份到电脑或其他安全位置。备份不包含原始音频，音乐、图片和 LRC 需要另外保存。
- **恢复不是合并**：导入备份会整库替换。卸载重装后，音乐目录权限也需要重新授予。
- **备份没有加密**：其中可能包含收藏、听歌记录与本地路径，不要上传公开仓库或问题反馈。
- **普通 LRC 不是逐字歌词**：整句时间戳无法准确描述每个字的停顿和拖音。逐字同步需要与音频版本匹配的增强歌词；工具生成结果仍需试听检查。

更多说明：[隐私与数据](PRIVACY.md) · [增强 LRC 格式](docs/HARMONY_ENHANCED_LRC.md)

## 从源码运行

仅开发或自行编译时需要。日常听歌不需要安装这些工具。

### 环境

当前验证组合：**Flutter 3.47.0 / Dart 3.13.0、JDK 21、Android SDK Platform 36**。安装 [Flutter SDK](https://docs.flutter.dev/install/archive) 和 Android 工具链，把 Flutter 加入 PATH，并运行 `flutter doctor -v` 检查环境。SDK 许可需要自行阅读并确认。

建议把 SDK 放在不含中文和空格的工具目录。项目只含 Android 平台工程；连接手机、开启 USB 调试并授权后，在项目根目录运行：

```sh
flutter pub get
flutter analyze --no-pub
flutter test --no-pub
flutter devices
# 将 ANDROID_DEVICE_ID 替换为上一步列出的 Android 设备 ID
flutter run -d ANDROID_DEVICE_ID
```

Windows 中文项目路径可优先使用项目脚本：

```powershell
.\tool.ps1 doctor
.\tool.ps1 get
.\tool.ps1 analyze
.\tool.ps1 test
.\tool.ps1 build-local-test
```

脚本从 `FLUTTER_ROOT`、本地 `.tooling/flutter` 或 PATH 查找 Flutter；JDK 使用 `JAVA_HOME` 或本地 `.tooling/jdk`。全新获取源码后，需自行安装工具，仓库不附带 SDK。

`build-local-test` 输出 `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`：使用 release 性能模式，但沿用本机调试证书，**不是正式公众签名包**。不同电脑的调试证书通常不同，不能保证覆盖已有安装。

正式构建需先配置被 Git 忽略的 `android/key.properties`，再运行 `tool.ps1 build-release`。签名不一致或版本过低时停止安装，不用卸载、清数据或强制降级绕过。签名、版本号及测试命令见[发布指南](docs/RELEASING.md)与[参与开发](CONTRIBUTING.md)。

### 项目结构

```text
lib/                        页面、交互、数据访问与播放业务
android/                    Android 媒体服务、目录访问、标签解析与构建
test/                       Flutter 与数据层回归测试
docs/                       使用说明、设计和验收记录
tools/harmony-music-intake/  可选的电脑音乐入库检查工具
tools/lyrics_alignment/     可选的电脑歌词对齐工具
```

电脑工具不打包进手机 App，也不是听歌的前置条件。默认测试使用合成数据；缺少真实输入时跳过的测试不算通过。后台、耳机和恢复等场景仍需设备或隔离环境验收。
