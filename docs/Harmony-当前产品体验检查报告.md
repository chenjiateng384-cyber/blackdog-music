# Harmony 当前产品体验检查报告

检查日期：2026-09-15

> 历史检查记录，不代表当前版本的验收结论。2026-11-03 开源整改发现了本报告当时未覆盖的备份回退风险；修复与当前已验证/未验证项见 [本轮交付记录](OPEN_SOURCE_DELIVERY.md)。下文设备数据、问题清单与版本仅适用于当时快照。

范围：音乐库、扫描与 Metadata、封面、歌词、搜索、歌单、播放、队列、首页、数据安全、性能与工程状态。

## 1. 总体结论

Harmony 的核心已经不是 Demo：真实目录扫描、Track/MediaFile 身份、Metadata、封面、LRC、播放队列、随心听、智能播放、歌单、搜索、播放历史、备份恢复都已经有实际实现和自动测试。

本轮没有发现会立即损坏收藏、歌单或播放记录的 P0 问题。数据库完整性正常，外键正常，扫描任务没有僵尸 running 记录，只有 missing 文件的 Track 默认不会出现在曲库。

但它还没有达到“完全可以停止开发”的程度。当前最大的差距不是数据库，而是：尚未完成两小时连续播放与完整恢复演练、设置页仍有占位入口、用户偏好数据还很少，以及代码版本和 Git 检查点没有跟上实际开发进度。

## 4. 本轮已修复

### P1：数据健康检查误报孤立歌手

原查询只检查歌手是否被 `track_artists` 使用，没有检查它是否仍作为有效专辑的 `album_artist`。因此 29 个仍被有效专辑使用的歌手会被误报为孤立数据。

修复后同时检查歌曲关系和专辑歌手关系。用真机数据库快照重新计算后，真正的孤立歌手为 0。已新增回归测试，确保以后不会再次误报。

## 5. 当前问题分级

### P0：影响正常使用

本轮未发现已复现的 P0 数据损坏或崩溃问题。

### P1：明显影响体验

1. **长时间稳定性仍需真实使用补齐。** Release 版已经完成安装、冷启动、列表滚动、状态恢复、媒体通知和后台保持检查，短时性能正常；但本轮没有完成连续 2 小时播放、耳机拔插、来电抢占和锁屏长时间测试，因此不能宣称所有场景 100% 完成。
2. **有 9 首历史 Track 暂时没有可用文件。** 它们已从正常曲库隐藏，不会形成幽灵重复；重新授权原目录并扫描后可能重新关联。为了保留喜欢、歌单和移动后的身份，本轮没有粗暴删除。
3. **个性化数据较少。** 目前只有 8 首喜欢、没有自定义歌单，658 首中只有 166 首有统计。随心听和智能播放虽然有防固化与探索逻辑，但可用信号仍然不足。
4. **英文歌缺少 21 份 LRC。** 这不是 App Bug；没有本地歌词文件时只能显示无歌词状态。
5. **“播放、歌词、外观”设置入口仍是占位。** 点击会提示后续开放，还不是完整可配置设置页。
6. **工程缺少新的稳定检查点。** 当前大量 V4 改动仍未形成新的 Git 基线，版本号仍为 `0.3.0+4`，与实际成熟度不符。继续开发前应做一次专门的版本整理和检查点，避免以后难以回退。

### P2：细节与维护

1. `app_controller.dart`、`v4_pages.dart`、`v4_player_page.dart` 等文件已经很大，后续改动容易互相影响。应在 UI 稳定后按现有边界小步拆分，不能现在大重写。
2. 有 16 个依赖存在较新但不兼容当前约束的版本；当前测试正常，不建议为了“最新版”立即升级。
3. 旧 README 与当前产品不一致，本轮已替换为当前说明，并新增独立使用手册。
4. 首次打开大量封面会产生缓存与解码成本；现有实现已按显示尺寸解码，仍需在 Release 真机上检查首次滚动和二次滚动差异。

## 6. 功能完成度判断

- 音乐扫描与目录保留：可日常使用。
- Track/MediaFile 身份与移动继承：可日常使用。
- FLAC/MP3/WAV Metadata 和封面：主体可用；特殊文件仍需真实样本回归。
- 音乐库、歌手、专辑、文件夹：主体可用。
- 播放、后台、Mini Player、歌词、队列：主体可用，仍需 Release 真机长时间验证。
- 搜索、喜欢、普通歌单、仅手动播放：可用。
- 随心听、智能播放：已有 V1 逻辑，需要靠真实使用积累偏好。
- 备份与恢复：实现和自动测试完成；卸载恢复仍建议用非唯一数据做一次完整真机演练。
- 设置中心：未完整完成。
- UI/交互抛光：尚未达到可以永远不改的程度。

因此当前更准确的定位是：**核心功能约 85%～90% 完成，日常产品体验约 75%～80% 完成。** 不是半成品，但也不是 100% 终版。

## 7. 推荐下一阶段顺序

1. **连续真实使用 7 天。** 不再凭截图大改 UI，只记录每天真正打断听歌的 3 个问题。
2. **补完整设置页。** 优先歌词偏移、主题、默认播放模式和队列行为。
3. **做卸载恢复演练。** 使用测试设备或明确可恢复的数据，不拿唯一真机数据冒险。
4. **建立 Git 检查点并更新版本号。** 完成后再进入下一轮视觉优化。

## 8. 完成标准

Harmony 真正进入稳定日用版，需要同时满足：

- Release 真机连续播放 2 小时无中断。
- 前后台往返、锁屏控制、耳机控制正常。
- 649 首当前曲库滚动和切页无明显掉帧。
- 备份导出、恢复、重新授权目录完整走通一次。
- 连续使用一周后，随心听不反复固定同一批歌曲。
- 不再出现需要返回两次、Mini Player 丢失、搜索点歌无播放状态等已知交互问题。
