# Harmony 使用手册

第一次安装只想尽快听歌，请先看[快速开始](QUICK_START.md)；本手册用于后续查细节，电脑整理工具不是使用 App 的前置要求。

## 1. Harmony 应该怎样使用

Harmony 适合承担两件事：

1. 保存和整理你已经合法取得、真正想长期保留的本地音乐。
2. 成为日常播放这些收藏的主要播放器。

发现新歌仍可使用你习惯的音乐平台；当一首歌值得长期收藏时，把音频和歌词整理进电脑音乐库，再同步到手机。Harmony 不需要替代“发现音乐”，它要替代的是“管理和播放自己的收藏”。

## 2. 推荐的电脑目录

```text
音乐文件/
├─ 周杰伦/
│  ├─ 歌手封面.jpg
│  ├─ 2000_Jay/
│  │  ├─ cover.jpg
│  │  ├─ 01_可爱女人.flac
│  │  └─ 01_可爱女人.lrc
│  ├─ EP与单曲/
│  └─ 演唱会Live/
├─ 邓紫棋/
├─ 英文歌/
└─ 零散单曲/
```

原则：

- 完整专辑：`歌手/年份_专辑/曲序_歌名.格式`。
- Live、EP、单曲使用明确目录，不伪装成正式专辑。
- 零散收藏可以放“英文歌”或“零散单曲”，不必强行建立专辑。
- 音频文件原位保留，Harmony 只读，不会替你移动或改名。

当前识别的音频扩展名：FLAC、MP3、WAV、M4A、AAC、OGG、OPUS。

## 3. Metadata 建议

优先使用可靠的文件自身标签。缺失时，明确的“歌名 - 歌手”文件名优先于普通分类目录；可靠歌手/专辑目录可作为补充。“英文歌”“单曲”“Music”等分类名不应当作歌手。

推荐至少写好：标题、歌手、专辑（完整专辑才写）、Track、Disc、年份。Metadata 正确时，Harmony 不会用目录猜测覆盖它。

合作歌曲可以保留完整 Artist，例如“周杰伦 & 杨瑞代”；主要歌手浏览会归入周杰伦，合作信息仍保留在歌曲信息和搜索中。

## 4. 封面放置规则

### 歌手封面

放在一级歌手文件夹内，例如 `音乐文件/周杰伦/歌手封面.jpg`。

程序支持以下文件名（扩展名可为 jpg、jpeg、png、webp）：

- `歌手封面`
- `artist`
- `portrait`
- `歌手`

歌手封面只在一级歌手目录识别，不要放在专辑子目录。

### 专辑和歌曲封面

同目录按以下顺序识别：

1. 与音频同名：`03_借口.flac` + `03_借口.jpg`。
2. 目录封面：`封面.jpg`、`cover.jpg`、`folder.jpg`、`front.jpg`、`album.jpg`。
3. 目录只有一张普通图片时，作为目录封面候选。
4. 音频内嵌封面仍是主要来源之一。

图片应小于 32 MB。添加图片后，在“我的 → 重新扫描音乐”执行一次扫描。

## 5. 歌词放置规则

最稳妥的方式是同目录、同文件名：

```text
03_借口.flac
03_借口.lrc
```

Harmony 也会尝试去掉曲序、空格和符号后匹配，但同名最安全。

普通 LRC 只有整句时间，Harmony 只能做到整句同步；停顿、拖音和逐字咬合需要逐字/逐词时间戳的增强 LRC。App 不能从普通 LRC 凭空得到准确的每字时间。

缺歌词的数量以你当前实际目录为准，不使用历史检查数字判断。缺失时补同名 LRC 后重新扫描。

## 6. 第一次在手机设置

1. 把整个“音乐文件”目录复制到手机，保持原有层级。
2. 打开 Harmony。
3. 进入“我的 → 主音乐目录”。
4. 在系统目录选择器中选中最外层“音乐文件”，授予长期读取权限。
5. 等待扫描完成，不要在扫描时反复退出或重新选择目录。
6. 检查“音乐库 → 文件夹”，确认周杰伦、邓紫棋、英文歌层级仍然存在。
7. 检查几个 FLAC、MP3、WAV 的封面、歌手、专辑、曲序和 LRC。

以后新增歌曲：电脑整理 → 复制到相同手机目录 → “我的 → 重新扫描音乐”。不要从 App 内把所有文件复制到另一个目录。

## 7. 日常使用方法

### 首页

- “随心听”：直接开始连续播放，偏熟悉和稳定，会动态补歌。
- “智能播放”：用于换口味，浏览当天稳定的本地候选，再自己选择。
- 搜索：从首页搜索框进入，搜索歌曲、歌手、专辑和歌单。

### 音乐库

- 歌曲：查看全部可播放 Track。
- 歌手：主要展示收藏量较足的歌手，合作歌手不会无意义拆满页面。
- 专辑：只展示满足收藏规则的专辑，按 Disc、Track 排序。
- 文件夹：严格按手机真实目录浏览，Metadata 失败时仍能找到文件。

### 歌单

- “我喜欢”表达强偏好。
- 普通歌单用于场景，例如“夜晚”“骑行”“健身”。
- “仅手动播放”表示歌曲仍保留、可搜索和手动播放，但不进入随心听与智能播放。

### 播放

- 点击 Mini Player 进入完整播放页。
- 播放页可切换封面、歌词和队列。
- 从专辑播放时，队列保持该专辑 Disc、Track 顺序；从歌单或文件夹播放时保持当前上下文。
- 暂停后继续属于同一次播放，不会重复增加播放次数。

## 8. 让 Harmony 真正懂你：30 天使用法

### 第 1 天

- 标记 20～40 首真正喜欢的歌曲。
- 把不希望自动出现的完整专辑低频歌曲加入“仅手动播放”。
- 创建 2～3 个真实会使用的歌单，不要为凑数量创建。

### 第 1 周

- 日常优先用 Harmony 播放。
- 喜欢就点爱心；不想自动听但要保留，就设为仅手动播放。
- 不需要专门训练算法，正常切歌、听完即可形成真实记录。

### 第 2～4 周

- 每周检查一次随心听是否仍过度重复。
- 为新收藏补齐封面和 LRC。
- 每次完成大量收藏或歌单整理后导出备份。

推荐质量需要真实偏好数据，也需要算法持续检查。不要把重复、卡住或错误归因于“你用得不够多”；这类问题应记录复现并修复。可以先日常使用一周，再比较随心听和智能播放是否仍过度重复。

## 9. 备份与恢复

进入“我的 → 数据与备份”。

备份未加密，包含私人收藏和听歌记录，不要发到公开仓库。恢复是整库替换，不是合并；恢复会停止播放。先在隔离环境验收备份，不要通过卸载唯一手机安装来试验。Android 系统自动备份不作为本 App 的恢复保障。

### 导出

1. 点击“导出备份”。
2. 选择手机公共目录、电脑可访问目录或网盘同步目录。
3. 保存生成的 `.harmonybackup`。

备份包含喜欢、歌单、顺序、播放记录、统计、人工修正、设置、人工封面和手动歌词；不包含原始音频文件，也不重复打包可重新生成的缓存。

### 恢复

1. 重装后先准备好原音乐目录。
2. 进入“我的 → 数据与备份 → 从备份恢复”。
3. 选择 `.harmonybackup`。
4. 恢复后重新选择原“音乐文件”根目录，因为 Android 卸载会撤销 SAF 授权。
5. 重新扫描，让文件重新关联到稳定 Track。

恢复会先验证备份并保护当前数据库；验证失败不会覆盖现有数据。

## 10. 常见问题

### 封面不显示

- 确认图片扩展名为 jpg/jpeg/png/webp。
- 确认文件名符合上面的规则。
- 歌手封面必须放在一级歌手目录。
- 图片不能超过 32 MB。
- 执行重新扫描。

### 歌曲或目录缺失

- 检查“我的 → 主音乐目录”是否仍有授权。
- 不要只选中某个专辑子目录；应选最外层音乐根目录。
- 重新扫描。

### 歌词对不上

- 先确认 LRC 与音频是同一个版本；Live、Remaster、伴奏不可共用时间轴。
- 普通 LRC 只能整句同步；逐字准确必须使用增强时间戳。
- 后续设置页完成后可用整体时间偏移修正统一早/晚问题。

### 页面卡顿

- 确认使用 Release APK，而不是调试 APK。
- 首次加载大量封面后再比较第二次滚动。
- 扫描期间不要做流畅度结论。
- 若 Release 仍持续卡顿，连接一加13后记录具体页面和操作，由性能数据定位，不能只靠肉眼猜。

## 11. 安全原则

- 不要卸载前忘记导出 `.harmonybackup`。
- 不要把唯一一份备份只放在 App 私有目录。
- Harmony 不会修改或删除原始音乐文件。
- 不要用“清数据”解决一般 Bug；先导出备份并报告复现路径。
