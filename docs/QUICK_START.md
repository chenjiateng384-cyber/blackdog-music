# 第一次使用黑狗音乐

面向想直接听歌的人，不需要先学习 Flutter、Git 或 AI 工具。

## 先确认能不能安装

- 当前只提供 Android 方向的测试候选版，主要验收一加13；不提供 iPhone、iPad 或桌面播放器。
- 目前尚未建立公开仓库和正式下载地址。不要在陌生网站寻找所谓“官方版”；发布状态以项目 README 为准。
- 正式下载开放后，进入仓库 Releases，选择说明中指定的 Android ARM64 `.apk`。`Source code.zip` 是开发者源码，不是手机安装文件。
- 已装旧版时，先在“我的 → 数据与备份”导出备份。签名不一致、版本过低或来源不明时停止，不卸载、清数据或关闭安全防护强装。

开发者要自己编译，请看 [README 的源码运行部分](../README.md#从源码运行)。[发布检查单](RELEASE_READINESS.md)是给维护者看的，不是首次听歌必须完成的作业。

## 第一次听歌：只做这 5 步

1. **准备文件。** 用自己有权使用的几首 MP3、FLAC 或 WAV 先试。歌曲不需要购买本 App 会员，也不会由 App 在线下载。
2. **复制到手机。** 新建一个固定目录，例如 `Music/我的收藏`，放入音频；有同名 LRC、封面也一起复制。不要把调试截图、旧备份和临时歌词混进音乐目录。
3. **授权目录。** 打开黑狗音乐，在底部“我的 → 主音乐目录”中选择刚才的收藏目录，在系统窗口确认“使用此文件夹”或同义按钮。
4. **等扫描结束。** 到“音乐库 → 歌曲”或“文件夹”查看，点一首歌；底部小播放器可以进入完整播放页。
5. **留下第一份收藏。** 点爱心、建歌单，随后去“我的 → 数据与备份”导出一份 `.harmonybackup` 到 App 外部，最好再复制到电脑。

App 默认只读取原始音乐，不替你移动或重写原文件。以后新增歌曲：复制到原音乐目录 → “我的 → 重新扫描音乐”。不用卸载重装。

## 没成功时先看这里

| 遇到什么 | 先做什么 |
| --- | --- |
| 首页播放按钮不能点 | 尚无可自动播放歌曲；先选择主音乐目录，也可到歌曲/文件夹手动点播 |
| 系统目录窗口的确认按钮是灰色 | 换成自己新建的音乐子目录，不要选整个内部存储、Download 根目录或 Android/data 等受限目录 |
| 扫描后 0 首 | 确认文件已复制完、选中了正确目录、文件是真正音频而不是平台加密缓存；检查扫描错误，再重新授权/扫描 |
| 文件夹能看到，主要歌手或专辑列表没有 | 零散曲目和收藏数量筛选可能导致该差异；先从歌曲/文件夹播放，不为显示数量乱改标签 |
| 缺封面 | 检查内嵌图片或同名图片、目录 `cover.jpg`；补图后重扫，缺图本身不妨碍听歌 |
| 缺歌词 | 可先正常听；需要时补与音频同目录同名的 LRC，再扫描 |
| 歌词整句跟随，但不能精准逐字 | 普通 LRC 不含逐字时间，暂停/拖音无法凭空推断；不是反复扫描就能解决 |
| 拔 USB 后不能播放 | 音乐必须实际保存在手机，电脑端文件不会通过 USB 自动变成持续可用曲库 |
| 锁屏一段时间后断播放 | 记录系统和机型，检查该 App 的后台/电池限制；不要为排查直接清数据 |
| 更新装不上 | 记录安装提示、旧/新版本和安装来源，停止操作并反馈，不先卸载 |

Android 11 起，系统对选择内部存储根目录、Download 根目录等位置有限制；这不是要求用户打开“所有文件访问权限”。选择专门的音乐子目录更容易核对范围。[Android 官方目录授权说明](https://developer.android.com/training/data-storage/shared/documents-files)

## 熟悉以后，再看这三件事

- **随心听**：不选歌，直接连续听；**智能播放**：先浏览候选再自己点选。
- **仅手动播放**：保留歌曲，但不让它进入这两套自动候选；不取消“我喜欢”，也不删除文件。
- **两份备份**：`.harmonybackup` 保护 App 数据；音频、LRC 和图片另做文件备份。不要把备份放进公开 Issue。

详细操作见[使用手册](Harmony-使用手册.md)。只有需要批量整理时，再看[收藏指南](LOCAL_MUSIC_COLLECTION_GUIDE.md)和[音乐后勤](MUSIC_OPERATIONS.md)；它们不是听第一首歌的前置要求。

提供 App 版本、手机与系统、安装包来源、具体操作步骤、预期与实际结果。例如：“音乐库 → 文件夹 → 点歌 → 返回 → 再点歌，第二次卡住，但声音仍继续”。截图先遮通知、私人路径等信息。

不要发送整首音乐、真实数据库、备份、账号或私钥。公开反馈使用仓库的问题模板，安全与数据风险按 [SECURITY.md](../SECURITY.md) 私下报告。
