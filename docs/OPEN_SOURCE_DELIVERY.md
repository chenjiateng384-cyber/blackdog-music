## 复查结果

- Flutter 静态检查：最终代码通过，0 个问题。
- Flutter 默认自动测试：240 项通过、4 项按输入条件跳过；最后一次在独立源码副本中重跑也通过。其中包含备份失败/资源/路径/并发、恢复后队列/搜索及扫描互斥回归。

- 电脑歌词工具：10 项通过；没有因此下载或修改用户歌词。
- APK：最终 ARM64 本地测试包构建成功，版本 0.4.6 / versionCode 2011，25,114,912 字节；证书与原手机包相同，覆盖安装成功。正式构建缺签名配置时正确拒绝，没有静默回退调试证书。
- 包内权限复查：没有 INTERNET，系统包标志没有 ALLOW_BACKUP；SDK 24 起，target 36。
- 手机：0.4.6 候选已实测文件夹点歌/返回/再次进入、搜索 Beyond 点歌、返回保留搜索词、Mini Player 再打开和媒体后台/锁屏命令。未复现原先全屏小播放器卡住；所采日志未出现本 App 的 Flutter 异常、SQLite 异常、FATAL 或 ANR。短时采样不是长期稳定性保证。

1. 首次远端 CI 和全新机器的克隆构建尚未实际执行；本机独立源码副本验证不能代替它。没有推送或公开仓库，也没有把先前未提交改动自动提交进原 Git 历史。
2. 专属正式签名尚未生成/启用；按用户选择先交付兼容测试包。唯一真机不卸载、不清数据。
3. 素材已获所有者可公开分发确认，来源与证明仍须补清单；依赖传递许可与最新安全公告还需发布前复核。
4. 两小时连续播放、音频焦点/耳机完整矩阵与卸载重装恢复演练，不能由现有单元测试替代。
5. 当前回退覆盖可捕获失败；操作系统在替换/设置写入中途杀进程的跨文件原子性尚未专门做故障注入验证，不声称完全覆盖断电。
6. 大文件代码暂不拆分；这是后续维护债务，不在数据修复中夹带大重构。
7. 当前 `file_picker` 仍有上游 Kotlin Gradle Plugin 迁移警告；当前固定工具链可构建。以后升级 Flutter 前必须先验证插件兼容，不在本轮为消除警告盲目升级依赖。
