# 黑狗音乐：首次源码发布说明

日期：2026-11-04。仓库：[chenjiateng384-cyber/blackdog-music](https://github.com/chenjiateng384-cyber/blackdog-music)，发布分支为 `main`。

## 这次提供什么

- Android 私人音乐库 App 源码、测试、构建配置和 MIT 许可证。
- 从准备音乐、配封面与歌词，到整理目录、传到手机、扫描和备份的教程。
- 可选电脑音乐入库检查与歌词对齐工具；不附第三方模型、SDK 或音乐资源。
- 所有者自行用 AI 生成并授权分发的狗狗图标；具体来源说明见[第三方声明](../THIRD_PARTY_NOTICES.md)。

没有上传私人音乐、完整歌词、真实数据库、收藏与播放记录、备份、私钥、缓存、旧截图或 Word 原件。原项目的私人开发历史不进入发布仓库；本地原件保留。

## 当前功能

按歌曲、歌手、专辑和真实文件夹浏览；本地搜索；喜欢与歌单管理、自选歌单封面；Mini Player、播放页、队列、后台与系统媒体控制；本地封面与 LRC；随心听、智能播放、仅手动播放排除；播放历史、音乐档案与外部备份恢复。实际使用方法见 [README](../README.md) 和[使用手册](Harmony-使用手册.md)。

## 普通用户能直接安装吗

**这次先提供源码，没有正式 APK 下载，也没有 iOS 或桌面播放器。** 首次源码预发布标记为 `v0.4.7-beta.1`，App 内部版本保持 `0.4.7+13`，Android 7.0+，主要验收设备是一加13。开发者可按 README 自行构建；不熟悉编译的用户请等待经过签名与验收的 Android 预发布安装包，不要把源码 ZIP 当安装包。

本地兼容测试包仍使用调试证书，不作为公众正式包上传。不要为安装新签名包而卸载唯一的 App 或清除数据；先导出外部备份，验证恢复与目录重新授权，再安排迁移。

## 版本与已知限制

- 所有者已确认使用 `v0.4.7-beta.1`，明确标为源码预发布；不采用与现有版本不符的 `v0.1.0`，不将旧提交误标为最新版本。
- 普通整句 LRC 不能提供可靠的逐字停顿、拖音时间；增强歌词也依赖准确的音频版本和时间戳，不承诺 AI 对齐绝对准确。
- 两小时连续播放、完整耳机/音频焦点矩阵、隔离 Android 卸载重装及 SAF 重新授权恢复仍待专项验收。
- 图标生成工具及原始记录尚未补齐；所有者的分发确认不是独立版权审计。其他来源不明或含私人收藏的图片没有随源码发布。
- 音乐获取站点是第三方参考，不是 App 下载服务，不保证持续可用，也不授权下载者再分发资源。
- 备份没有加密，不能上传公开 Issue。数据不足时，推荐和统计不代表长期稳定结论。
